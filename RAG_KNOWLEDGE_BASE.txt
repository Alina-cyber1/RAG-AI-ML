=== ТЕМА 2: НЕЙРОННЫЕ СЕТИ И KERAS ===

Нейронная сеть — это математическая модель, имитирующая работу человеческого мозга. Состоит из слоев нейронов.

Keras — высокоуровневый API для нейронных сетей.

Sequential модель:
model = Sequential()
model.add(Dense(64, activation='relu', input_shape=(784,)))

Функции активации:
- ReLU: max(0,x) — для скрытых слоёв
- Sigmoid: 1/(1+e^-x) — бинарная классификация
- Softmax: e^x_i / sum(e^x_j) — многоклассовая классификация
- Linear: f(x)=x — регрессия

Loss функции:
- categorical_crossentropy — многоклассовая (one-hot)
- binary_crossentropy — бинарная
- mse — регрессия

Оптимизаторы: Adam, SGD, RMSprop

=== ТЕМА 3: ГРАДИЕНТНЫЙ СПУСК ===

Градиентный спуск — это метод оптимизации для минимизации функции потерь.

Принцип работы:
1. Вычисляем градиент (производную) функции потерь
2. Делаем шаг в противоположном направлении градиента
3. Повторяем, пока не достигнем минимума

Формула: θ = θ - η * ∇J(θ), где η — learning rate (скорость обучения)

Оптимизаторы на основе градиентного спуска: SGD, Adam, RMSprop, Adagrad

=== ТЕМА 4: СВЁРТОЧНЫЕ НЕЙРОННЫЕ СЕТИ (CNN) ===

CNN (Convolutional Neural Network) — сверточная нейронная сеть для обработки изображений.

Основные компоненты:
- Conv2D: сверточный слой (применяет фильтры к изображению)
- MaxPooling2D: уменьшает размерность (берет максимальное значение в окне)
- Flatten: преобразует 2D в 1D для полносвязных слоев

Параметры Conv2D:
- filters: количество фильтров
- kernel_size: размер ядра свертки (3x3, 5x5)
- padding: 'same' (сохраняет размер) или 'valid' (уменьшает)
- activation: функция активации ('relu', 'sigmoid')

YOLO (You Only Look Once) — для детекции объектов.

=== ТЕМА 5: РЕКУРРЕНТНЫЕ СЕТИ (LSTM, RNN) ===

LSTM (Long Short-Term Memory) — тип рекуррентной нейронной сети, решающий проблему затухающего градиента.

Особенности LSTM:
- Сохраняет информацию на длительное время
- Имеет три "вентиля": входной, забывающий, выходной
- Используется для последовательных данных: текст, временные ряды, аудио

RNN (Рекуррентная нейронная сеть) — сеть с обратными связями, подходит для последовательных данных.

Области применения:
- NLP — обработка текста, машинный перевод
- Прогнозирование временных рядов
- Распознавание речи

=== ТЕМА 7: RAG СИСТЕМЫ (RETRIEVAL-AUGMENTED GENERATION) ===

RAG (Retrieval-Augmented Generation) — подход для улучшения ответов LLM с использованием внешней базы знаний.

Этапы построения RAG-системы:
1. Загрузка документов в базу знаний
2. Разбиение на чанки (оптимальный размер: 800-1000 символов)
3. Создание эмбеддингов (векторных представлений)
4. Сохранение в векторную базу данных (FAISS, ChromaDB)
5. При запросе — поиск релевантных чанков
6. LLM генерирует ответ с найденным контекстом

Это решает проблему "галлюцинаций" LLM и позволяет использовать актуальные данные.

LangChain — фреймворк для приложений с LLM (PromptTemplate, LLMChain, VectorStore, RetrievalQA)

=== ТЕМА 8: PYTORCH ===

PyTorch — фреймворк машинного обучения с динамическими графами вычислений.

Основные возможности:
- Динамические графы (Define-by-Run) — более гибкий, чем TensorFlow
- Автоматическое дифференцирование (autograd)
- Поддержка GPU (CUDA)

Пример создания модели:
import torch.nn as nn
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 10)
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        return self.fc2(x)

DataLoader для батчей:
from torch.utils.data import DataLoader, TensorDataset
loader = DataLoader(dataset, batch_size=32, shuffle=True)

=== ТЕМА 18: ТРАНСФОРМЕРЫ (BERT, T5, GPT) ===

Трансформеры — архитектура нейронных сетей на основе механизма внимания (attention). Это основа современных LLM.

Ключевые модели на трансформерах:
- BERT (Bidirectional Encoder Representations from Transformers) — для понимания текста (классификация, QA, NER)
- GPT (Generative Pre-trained Transformer) — для генерации текста
- T5 (Text-to-Text Transfer Transformer) — универсальная модель (всё как задача перевода текста в текст)

Механизм внимания (Attention):
- Позволяет модели "фокусироваться" на важных частях входного текста
- Self-attention — внимание внутри последовательности
- Multi-head attention — несколько "голов" внимания параллельно

Преимущества трансформеров над RNN/LSTM:
- Параллельная обработка (не последовательная)
- Лучшее понимание длинных зависимостей
- Масштабируемость

=== ТЕМА 27: AIRFLOW И MLOPS ===

Airflow — оркестрация пайплайнов (DAG — Directed Acyclic Graph).

Пример DAG:
from airflow import DAG
from airflow.operators.python import PythonOperator
from datetime import datetime

def train():
    print("Обучение модели")

def evaluate():
    print("Оценка модели")

dag = DAG('ml_pipeline', start_date=datetime(2024,1,1), schedule_interval='@daily')
task1 = PythonOperator(task_id='train', python_callable=train, dag=dag)
task2 = PythonOperator(task_id='evaluate', python_callable=evaluate, dag=dag)
task1 >> task2  # зависимости

MLflow — управление lifecycle ML моделей:
mlflow.log_param("lr", 0.001)
mlflow.log_metric("accuracy", 0.95)
mlflow.log_model(model, "model")

MLOps — практики CI/CD для ML:
- Автоматическое обучение
- Валидация моделей
- Мониторинг дрейфа данных

- Broker — сервер Kafka

Пример producer:
from kafka import KafkaProducer
producer = KafkaProducer(bootstrap_servers='localhost:9092')
producer.send('my-topic', b'Hello Kafka')

Пример consumer:
from kafka import KafkaConsumer
consumer = KafkaConsumer('my-topic', bootstrap_servers='localhost:9092')
for msg in consumer:
    print(msg.value)

Применения:
- Логирование
- Event-driven архитектуры
- Обработка данных в реальном времени
